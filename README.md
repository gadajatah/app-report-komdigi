### TL;DR
### Laravel Inertia React with TypeScript

#### Features

- Authentication
- User Profile
- User Password
- User Deletion
- Lapordigi

#### How to run project
- clone from github https://github.com/gadajatah/app-report-komdigi.git
- composer install
- npm install && npm run build
- cp .env.example .env
- setup database with local database
- php artisan migrate:fresh --seed
- php artisan serve
- Klik link/url local
